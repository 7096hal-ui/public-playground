# 꿀꿀 고추 사냥

도심 빌딩 옥상 사이를 뛰어다니며, 하늘을 날아다니는 고추를 잠자리채로 잡으러 다니는 횡스크롤 플랫폼 게임.
주인공 꿀꿀이는 돼지 인형옷을 입고 머리에 곤충 더듬이를 단 개구쟁이다.

ver.3부터는 도시가 3D로 그려진다. 게임 판정은 예전처럼 2D 그대로이고, 그 뒤로 입체 도시와 하늘이 펼쳐진다.

플레이: https://7096hal-ui.github.io/public-playground/

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | ← → (또는 A D) | ◀ ▶ 버튼 |
| 점프 | Space / Z / ↑ (길게 누르면 높이) | 점프 버튼 |
| 잠자리채 휘두르기 | X (또는 J) | 채 버튼 |
| 일시정지 | P / Esc | Ⅱ 버튼 |
| 소리 켜기/끄기 | M | |

새 장치들은 닿기만 하면 작동해서, 버튼은 늘지 않았다.

터치 버튼은 손가락 여러 개를 동시에 눌러도 된다. 엄지를 ◀ ▶ 사이로 미끄러뜨리면 바로 방향이 바뀌고, 버튼 그림을 조금 벗어나도 눌린 것으로 친다.

## 스테이지

1. 「아침 빌딩 숲」: 기본기, 옥상 트램펄린
2. 「한낮의 공사장」: 창문 청소 곤돌라, 크레인 철골 발판, 비계
3. 「노을 상가 거리」: 짚라인, 밟으면 떨어지는 낡은 간판, 환풍구 상승 기류
4. 「한밤의 네온 옥상」: 네온사인 거리, 곤돌라를 타고 탑 꼭대기로
5. 「폭풍우 마천루」: 비와 번개, 주기적으로 번개가 내리치는 피뢰침
6. 「대왕 고추」: 헬기장 옥상에서 보스전

## 규칙

- 목숨 3개로 시작한다. 철조망, 성난 비둘기, 크레인 쇳덩이, 피뢰침 번개, 대왕 고추와 고추씨에 닿거나 건물 사이 골목으로 떨어지면 목숨이 1 줄어든다.
- 고추를 잡으면 100점. 2.2초 안에 또 잡으면 콤보가 붙어 점수가 배로 늘어난다(최대 8배).
- 반짝이는 황금 고추는 500점.
- 스테이지를 깨면 별 1~3개와 보너스 점수를 받는다.
  - 보너스: 전부 잡기, 무사고, 시간, 콤보
  - 고추를 전부 잡으면 목숨 +1
- 아이템 방울
  - 왕잠자리채: 채가 훨씬 길어진다
  - 돼지 날개: 공중에서 한 번 더 점프
  - 자석 더듬이: 근처 고추가 끌려온다
  - 하트: 목숨 +1
- 대왕 고추는 내리꽂힌 뒤 어질어질할 때만 잠자리채로 맞힐 수 있다. 체력을 다 깎으면 작아지는데, 그걸 잡으면 끝.
- 최고 점수는 브라우저에 저장된다.

## 장치

- **트램펄린**: 밟으면 높이 튀어 오른다.
- **곤돌라**: 위아래로 오르내린다. 타고 있으면 같이 움직인다.
- **철골 발판**: 크레인에 매달려 좌우로 오간다.
- **짚라인**: 점프해서 줄에 닿으면 매달려 끝까지 내려간다. 점프하면 중간에 놓는다.
- **환풍구**: 바람 기둥 안에 들어가면 둥실 떠오른다.
- **낡은 간판**: 밟고 0.5초 뒤에 떨어진다.
- **피뢰침**: 불꽃이 튀면 곧 번개가 내리친다.

버전마다 `main`의 태그로 남긴다(GitHub의 Releases / Tags에서 볼 수 있다).

| 태그 | 내용 |
| --- | --- |
| `v1_grass_field` | ver.1: 들판 배경 |
| `v2_rooftop_city` | ver.2: 도심 옥상 배경 |
| `v3_3d_skyline` | ver.3 (파일럿): 3D 도시, 스테이지 6개, 새 장치, 점수·콤보, 보스, 배경음악 |

## 개발

```bash
npm install
npm run dev      # 로컬 개발 서버
npm run build    # dist/ 로 빌드
npm run preview  # 빌드 결과 미리보기
```

주소 뒤에 붙이는 확인용 옵션:

| 옵션 | 하는 일 |
| --- | --- |
| `?debug` | 판정 칸을 빨간 선으로 보여 준다. 3D 건물과 맞는지 확인할 때 쓴다. |
| `?2d` | 3D 없이 예전 2D 그림으로 그린다. WebGL이 안 되는 기기에서는 저절로 이렇게 된다. |
| `?fixedq` | 느린 기기에서 3D 해상도를 자동으로 낮추는 기능을 끈다(테스트용). |

## 구조

```
src/main.js      캔버스 크기 조정, 게임 루프, 터치 버튼, 3D 켜기
src/game.js      게임 진행(타이틀·소개·플레이·클리어·게임오버·엔딩), 판정, 점수, 카메라
src/render2d.js  2D 덧그림: 주인공·고추·장애물·HUD·결과 화면
src/world3d.js   3D 도시 (three.js): 건물, 옥상 소품, 간판, 배경 빌딩, 하늘, 구름, 비
src/atlas.js     3D 간판·광고판 그림을 캔버스 한 장에 그림
src/themes.js    스테이지 분위기(아침·한낮·노을·한밤·폭풍우·결전)
src/levels.js    스테이지 설계 — 여기서 스테이지를 고치거나 추가한다
src/level.js     스테이지 데이터를 실제 플레이용으로 만듦
src/player.js    주인공 조작감(속도·점프 높이 등 수치가 맨 위에 있음), 짚라인·아이템
src/entities.js  고추, 비둘기, 쇳덩이, 발판, 곤돌라, 간판, 트램펄린, 짚라인, 환풍구, 피뢰침, 아이템
src/boss.js      대왕 고추의 움직임
src/physics.js   타일 충돌 처리
src/draw.js      예전부터 있던 그림 (주인공, 고추, 비둘기, 2D 배경…)
src/sprites.js   ver.3에서 생긴 것들의 그림
src/audio.js     효과음 (파일 없이 Web Audio로 생성)
src/music.js     배경음악 8곡 (파일 없이 Web Audio로 연주)
src/input.js     키보드·터치 입력
```

3D가 판정과 어긋나지 않는 이유: 건물 앞면을 정확히 z = 0 평면에 놓고, 카메라를 기울이지 않고 정면으로만 보게 했다(눈높이는 렌즈 시프트로 올림). 그래서 z = 0 평면은 화면에 확대와 이동만으로 대응되고, 위에 겹친 2D 캔버스와 1픽셀까지 맞는다.
